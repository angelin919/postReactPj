# 📝 Посты JSONPlaceholder — React-приложение

Учебный проект, созданный в рамках курса ASTON.
Приложение получает и отображает посты из публичного API JSONPlaceholder, демонстрируя работу с React, TypeScript и асинхронными запросами.

## 🛠 Технологии

- **Frontend:** React, TypeScript
- **Маршрутизация:** React Router DOM
- **Сборка:** Vite 
- **Контроль версий:** Git
